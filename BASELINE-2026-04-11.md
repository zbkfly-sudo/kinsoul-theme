## 🚨 NEW Critical Findings (audit didn't catch)

### 1. The H1 culprit is **Klaviyo email popup**, not theme code

Every page (homepage, about, materials, client-care, contact, collection, PDP) shows an extra `<h1>Join Our Kinsoul Family</h1>` from a Klaviyo popup form. DOM ancestors:

```
H1
└─ DIV#rich-text-01KNP0Y5QNKJGQANT4YXKSPNZP.kl-private-reset-css-Xuajs1
   └─ DIV.needsclick.kl-private-reset-css-Xuajs1
      └─ FORM.klaviyo-form.klaviyo-form-version-cid_1
```

**Implication:** This is a **Klaviyo dashboard fix**, NOT a Shopify theme fix.
- The user must edit the popup form in **Klaviyo Forms editor** and change the heading element from `<h1>` to `<h2>` (or `<p class="header">`).
- No code change can fix this; the form HTML is injected at runtime by Klaviyo's external script.

### 2. Materials page title is being truncated by Shopify

```
"Materials & Craft — Natural Pearls, Gemstones & Sterling Silver | Kins – Kinsoul Energy"
```

The "Kins" is an artifact of Shopify auto-appending " – Kinsoul Energy" to a title that's already over 60 characters. **Admin SEO title** field needs to be shortened.

## Decision impact

The Phase 0 results materially shrink the code change scope:

- **Phase 1 (code foundation):** ~50% smaller — Product schema wiring removed
- **Phase 2 (H1 fix):** Mostly **NOT a code task** — primarily Klaviyo admin fix
- **Phase 3 (AI crawlers + llms.txt):** Unchanged
- **Phase 4 (FAQ schema):** Unchanged
- **Phase 5 (Admin tasks):** Larger — gained Klaviyo, materials title, About content

The user gets fewer code changes (less risk) but more admin todos (more agency). This is the right tradeoff because **admin fixes are reversible without rollback complexity**.
