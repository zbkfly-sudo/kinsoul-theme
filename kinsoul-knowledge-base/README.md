## 使用规则

1. 所有博客写作前先读 `00-voice-guide.md` + `08-brand-positioning.md`
2. 文章涉及具体主题(产品 / 供应链 / 客户 / 实验)时补读对应文件
3. 写完每篇先过 `07-forbidden-expressions.md` 的禁用词扫描
4. 冲突时以本目录为权威,线上 / 本地 / CLAUDE.md 不一致的地方一律以本目录为准改
